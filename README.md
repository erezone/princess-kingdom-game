# Princess Kingdom Adventure 👑

A browser-based 2D top-down adventure game where you play as a princess exploring her magical kingdom!

## 🎮 Play

Visit the live game: [Play Now](https://erezone.github.io/princess-kingdom-game/)

## 🕹️ Controls

- **Arrow Keys / WASD** — Move the princess
- **Space** — Talk to villagers / advance dialog

## 🌍 Zones

- **Royal Castle** — Your home, where the King and Royal Advisor await
- **Cozy Village** — Meet friendly villagers and learn about the quest
- **Enchanted Forest** — Explore the magical woods and find hidden gems

## ✨ Objective

Collect all magical gems scattered across the kingdom to restore peace to the Enchanted Forest!

## 🛠️ Tech

Pure HTML5 Canvas + vanilla JavaScript. No dependencies, no build step.
